# StevePreviewer

用于 **Blockbench 桌面版 5.2.2 及以上版本**的原版 Steve 开发预览插件，仅在 **Bedrock Entity / 基岩版实体模型**格式中启用。接口按 5.2.2 源码核对，更新版本的实际兼容性仍需宿主验证。

## 安装

1. 在 Blockbench 的“文件 → 插件”中选择“从文件加载插件”。
2. 选择 [`dist/steve_previewer.js`](dist/steve_previewer.js)。
3. 打开基岩版实体工程，在建模或动画页面的 OUTLINER 下方工具栏左侧按钮组中点击人形图标“预览 Steve 模型”。

如已安装旧名称插件，请先卸载旧插件，再加载新文件。

交付的 JS 内已包含模型数据和 PNG 贴图，不需要联网，也不需要将 `assets/` 复制到 Blockbench。`src/` 中的是构建模板，安装时请选择 `dist/` 中的文件。

插件管理器的“关于”页提供简短功能说明，内容来自 [`about.md`](about.md)，构建时一并内嵌到交付 JS。当前已实现基岩原版 Steve 预览，描述中提到的网易版 4D 标准模型预览尚未实现。

## 使用

- **开启预览**：将 Mojang 官方玩家骨架及方块加入当前工程，包含 17 个骨骼、12 个方块和 64×64 Steve 皮肤。骨骼可直接选中和制作动画，自己的模型可挂到这些骨骼下。
- **预览标记**：插件新建的 Steve 骨骼和预览方块在骨骼树中带青色虚线、图标颜色及 `STEVE · 预览` 标记，不改变骨骼名称；复用的原有骨骼保留原显示。
- **独立皮肤**：Steve 使用插件私有材质和 64×64 UV。插件不会向工程的贴图列表添加皮肤，不改变默认贴图、现有模型的 UV 或工程贴图尺寸。实体自身的贴图选择不影响 Steve 的显示。
- **关闭预览**：只移除插件新增的 Steve 骨骼和预览方块，暂存其结构、编辑数据及 UUID；复用的原有骨骼及其内容保留，Steve 动画轨道和关键帧保留。再次开启时优先恢复原 UUID，已有同名骨骼则直接复用。
- **自建挂载内容**：关闭时若插件新增的 Steve 骨骼下存在自建内容，弹出只有“移至顶层”和“删除”两个选项的对话框。复用骨骼下的原有内容不触发此提示。关闭按钮和 Esc 不会代选。“移至顶层”保留对象的坐标数值、局部旋转及内部层级，不烘焙 Steve 父骨骼或当前动画产生的变换；“删除”同时删除自建内容及其子级，对应自建骨骼轨道遵循宿主原生删除行为。
- **同名骨骼**：按名称精确匹配，已有同名骨骼时直接把预览方块添加到该骨骼下，不提示冲突，也不添加前缀。原有骨骼的层级、枢轴、旋转和导出设置保持原值，只补建缺少的骨骼。
- **撤销和恢复**：开关操作、自建内容处理和暂存状态在同一次原生 Undo 操作中记录，可使用 Ctrl+Z / Ctrl+Y。

没有“添加 Steve 模型”功能，没有工具栏下拉菜单。

## 保存与导出

**保存 `.bbmodel`** 会保留正在预览的节点、动画及关闭状态下的 Steve 暂存数据。插件将暂存状态放在宿主原生 `unhandled_root_fields.modeling_based_on_steve` 字段中，避免仅靠内存保存；改名后继续沿用此字段以兼容已有工程。重新打开工程后仍需加载本插件以恢复独立皮肤及预览标记。

**导出基岩版 `.geo.json`** 不包含 Steve 的 12 个预览方块，也不包含仅供预览的空骨骼。集合单独导出时，插件也会在原生编译前暂时排除 Steve 块，编译后恢复对象标志。若自己的模型挂在 Steve 骨骼下，插件保留这些内容所必需的父骨骼，保证层级和动画关系。插件不会打包或导出 Steve 贴图。

**导出基岩版动画** 使用 Blockbench 原生动画导出器。Steve 轨道按正常骨骼名称导出；关闭预览时仍可导出保留的轨道。要让这些轨道在游戏中产生效果，运行时模型需要包含对应名称的骨骼。

支持范围是基岩版实体几何与动画。其他格式及 OBJ、glTF 等通用导出器不在本插件的导出过滤范围内。

停用或卸载插件会清理按钮、样式、事件、对话框及私有材质；不删除工程内的骨骼、方块、动画或暂存数据。预览节点保留原生“禁止导出”标志。其他已打开工程的 Steve 材质会被清空，当前工程恢复宿主常规显示；再次加载插件可恢复 Steve 皮肤。若希望工程中也移除 Steve 节点，请先关闭预览再卸载。

## 目录与构建

| 路径 | 用途 |
| --- | --- |
| `src/steve_previewer.js` | 插件逻辑及内置资源占位符 |
| `about.md` | 插件管理器中显示的简短关于页 |
| `assets/steve.geo.json` | Mojang 原始玩家几何与骨架 |
| `assets/steve.png` | Mojang 原始 Steve 皮肤 |
| `assets/Mojang-LICENSE.md` | 原资源附带的使用条款 |
| `build.ps1` | 将几何、PNG 和关于页内嵌到单文件插件 |
| `dist/steve_previewer.js` | 可加载的插件交付文件 |

在此目录使用 PowerShell 7 构建：

```powershell
pwsh -NoProfile -File ./build.ps1
```

无需 Node 依赖、npm 安装或打包工具。
